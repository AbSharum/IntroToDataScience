# Intro to Data Science Coursework

Jupyter notebook labs, problem sets, and a final project from an Introduction to Data Science course.

## Contents

- `Final Project/` — Analysis of Dubai used-car listing prices (`dubaiCars.csv`), with an exported HTML report and write-up.
- `Labs/Lab1-8` — Notebooks covering IMDB data, credit-card customer segmentation, a happiness index, Amazon bestsellers, salary regression, and iris classification.
- `Problem Sets/PS1-3` — Supporting problem sets.

## Stack

Python (pandas, Jupyter).

## Running

```
pip install jupyter pandas numpy scikit-learn matplotlib
jupyter notebook
```

Then open any `.ipynb` file.
